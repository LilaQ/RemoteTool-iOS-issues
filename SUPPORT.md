# RemoteTool Support

## Before Filing an Issue

1. Confirm the Mac Host is running and has Screen Recording and Accessibility permission.
2. Keep both devices on the same LAN for Free mode. Premium manual access uses a Tailscale/WireGuard address and TCP port `49152`.
3. Generate a new pairing code and try again.
4. For purchases, use Settings → Restore Purchases and confirm that the same Apple Account is active.

Include app version/build, iOS/iPadOS and macOS versions, connection type, product type without transaction identifiers, and reproducible steps. Redact IP addresses, device names, pairing codes, tokens, clipboard contents, purchase receipts, and private screen content.

**RELEASE BLOCKER:** An owner-approved private support email and response policy must be added before distribution.
