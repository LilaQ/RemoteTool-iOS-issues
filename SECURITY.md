# Security Policy

Do not disclose vulnerabilities in public issues. Public reports may expose pairing, device, network, purchase, or screen information.

**RELEASE BLOCKER:** The publisher must provide an owner-controlled private security reporting address, supported-version policy, acknowledgement target, remediation target, and coordinated-disclosure process before release.

RemoteTool currently requires an independent protocol review, StoreKit entitlement review, fuzz testing, and penetration test before public distribution.
