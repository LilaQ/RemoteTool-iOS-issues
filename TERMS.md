# Roamote — Terms / Nutzungsbedingungen

## English

Use Roamote only for devices, accounts and content you own or are authorized to access. You control device security, paired-device access, system permissions and Terminal commands. Shell commands can change or delete files and stop processes; use them with the same care as commands entered locally. Closing a session may terminate foreground commands. No subscription is required: Premium is a one-time in-app purchase for the current Premium features.

[Apple’s Standard Licensed Application End User License Agreement](https://www.apple.com/legal/internet-services/itunes/dev/stdeula/) applies to App Store distribution.

## Deutsch

Nutze Roamote nur für Geräte, Konten und Inhalte, die dir gehören oder für die du eine Zugriffsberechtigung hast. Du verwaltest Gerätesicherheit, gekoppelte Geräte, Systemfreigaben und Terminal-Befehle. Shell-Befehle können Dateien verändern oder löschen und Prozesse beenden; behandle sie mit derselben Sorgfalt wie lokal eingegebene Befehle. Das Schließen einer Sitzung kann Vordergrundbefehle beenden. Premium ist ein einmaliger In-App-Kauf für die aktuellen Premium-Funktionen, kein Abonnement.
